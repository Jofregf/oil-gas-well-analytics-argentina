# Oil & Gas Well Analytics — Argentina

🚧 Project under development

This repository contains an end-to-end Data Analytics project based on official oil and gas production and hydraulic fracturing datasets published by the Secretaría de Energía de la Nación Argentina.

The project follows a complete analytics workflow including:

- Business Understanding
- Data Audit
- Data Preparation (MySQL)
- SQL Analytics
- Python Analysis
- Power BI Dashboard
- Business Insights

The repository is currently under development.
